# 同频4K

手机端与电视端的项目归档，当前手机版本 **1.3.7 / 1370**，电视版本 **1.3.3 / 1303**。

## 参与开发

欢迎 Fork 仓库、创建分支并提交 Pull Request。问题反馈和功能建议请提交 [Issue](https://github.com/TongpinAI/tongpin-4k/issues)，参与步骤与验证要求见 [贡献指南](CONTRIBUTING.md)。

## 目录

- `tongpin-4k/`：手机 Java、资源、smali、测试、设计与发布校验记录。
- `tongpin-4k-tv/`：电视 Java、资源、测试、构建脚本与锁定的 Media3 依赖。
- `kanke-noads/decoded/`：手机构建校验必需的前四个 DEX 的基线 smali。
- `docs/PHONE_BUILD_INPUTS.md`、`docs/TV_BUILD_INPUTS.md`：完整构建输入与本机环境要求。
- `artifacts-manifest.json`：Release 附件的恢复路径、大小及 SHA256。

当前功能包括4K优先、实际解码尺寸短时显示、正倒序选集、上一集/下一集、倍速、自动连播、断点续播及手动解码方式切换。新增手机画面长按临时2倍速，保持按住向右拖动切到3倍速；电视画面焦点下长按确认键临时2倍速，松开均恢复原速度。实际文字字幕轨默认优先中文，可手动切换或关闭。电视倍速需安卓6及以上；片源标签不代表实测4K。

公开片库保留原8组来源，新增虎牙资源、暴风资源、奇艺资源3组第三方JSON接口。分类使用每个来源实际声明的ID与层级；不同来源的相同数字ID不能互换。接口可用性、剧集更新、4K画质和字幕轨均由上游提供，不能保证片库齐全或每部都有4K／中文字幕。

## 安装包与构建输入

`v1.3.7` Release 保存手机1.3.7、TV1.3.3安装包；`v1.3.6`保存上一版安装包、1.3.5／TV1.3.1基线包及完整Android工具v2归档；`backup-2026-11-06`保留更早的构建合同所需基线APK。安装包不放入Git源码历史。

在仓库根目录用已登录的 GitHub CLI 下载附件后恢复：

```powershell
gh release download backup-2026-11-06 --dir artifacts
gh release download v1.3.6 --dir artifacts
gh release download v1.3.7 --dir artifacts
python scripts/restore_artifacts.py --download-dir artifacts --check-only
python scripts/restore_artifacts.py --download-dir artifacts
```

恢复脚本先验证全部附件，再恢复到清单指定位置；不会覆盖内容不同的现有文件。Android 工具归档只包含当前构建所需的 Apktool、Platform35 与 Build Tools35.0.1 文件，v2补齐Java8编译所需的core-lambda-stubs.jar。

## 构建边界

这是现有工程的完整源码与必要输入归档，手机工程包含既有 APK 的资源与 smali，尚非完整 Android Studio/Gradle 重写项目。子目录 README 保留历史版本记录，以本页、PRODUCT.md 和最新发布校验记录为当前版本依据。

现有构建脚本仍使用 Windows、Python3.11+、本机 JDK/JBR 与 ASCII 目录别名。恢复附件后，请先阅读两端的构建输入说明与电视 `BUILDING.md`。发布合同刻意不覆盖已有正式包；继续发布需要创建新版本并更新对应合同，不能把归档脚本当作无条件重建命令。

签名私钥和密码不在仓库或 Release 中。要继续给已安装应用覆盖升级，必须在本机恢复原有签名材料；不要创建新密钥后声称签名仍兼容。

## 归档范围

保留源码、资源、图标、测试、设计文档、依赖锁表及发布校验资料；排除签名秘密、原始播放探测记录、缓存、重复安装包与普通中间编译产物。当前构建直接依赖的校验 class 和六份历史 R.java 夹具例外保留。

自有代码与第三方代码、资源、工具的许可各自适用。电视运行库的完整许可位于 `tongpin-4k-tv/assets/third_party_licenses/`，依赖来源与哈希位于其 `third-party/` 锁表。


## 1.3.5 修复

选集按当前线路的唯一正片集号统计，陪看／彩蛋另计，不从最大集号或上游简介推断完结。手机海报空评分隐藏，缺图时显示清晰品牌占位；此项不代表已找回失效的上游海报。水印由视频来源决定，当前接口未提供可靠水印标志，应用没有把未经验证的线路标成无水印。两端既有4K优先、进度、解码与连播保持。

## 1.3.6／电视1.3.2 验证范围

发布检查包含策略／解析器测试、真实接口分类样本、编译、实际DEX的调用与安卓版本隔离、资源ID、签名和覆盖升级证书检查。没有连接安卓手机或电视执行本机播放与遥控器验收。字幕仅切换视频提供的文字轨，不自动翻译，也不能关闭已经压入画面的字幕。

## 1.3.7／电视1.3.3 修复

手机原首页使用返回的筛选字段构造请求，切换条件时清空旧卡片并拒绝过期响应，修复分页与失败重试。海外页去掉内地选项；香港、台湾选择使用来源实际存放这些剧集的电视剧目录。上游部分作品的地区元数据本身有误，客户端没有按片名猜测或重写国家，也不把来源的总数当作已验证的片库完整度。

两端的集数同时区分最高集号和实际可选正片数。例如某线路列到177集但缺第8、39集时，显示“更新至第177集 · 可选175集”；陪看、彩蛋、人物志等另计。

手机原图加载失败后才后台尝试补图，先查同一原记录的最新封面，再以同名、年份、类型和长简介严格匹配已有配置来源。补图有并发、读入、图片尺寸及缓存上限；无法可靠确认的海报继续使用占位。未连接设备执行触摸、遥控或持续播放验收。
