# 同频4K

手机端与电视端的项目归档，当前手机版本 **1.4.8 / 1480**，电视版本 **1.4.2 / 1402**。

## 参与开发

欢迎 Fork 仓库、创建分支并提交 Pull Request。问题反馈和功能建议请提交 [Issue](https://github.com/TongpinAI/tongpin-4k/issues)，参与步骤与验证要求见 [贡献指南](CONTRIBUTING.md)。

## 目录

- `tongpin-4k/`：手机 Java、资源、smali、测试、设计与发布校验记录。
- `tongpin-4k-tv/`：电视 Java、资源、测试、构建脚本与锁定的 Media3 依赖。
- `kanke-noads/decoded/`：手机构建校验必需的前四个 DEX 的基线 smali。
- `docs/PHONE_BUILD_INPUTS.md`、`docs/TV_BUILD_INPUTS.md`：完整构建输入与本机环境要求。
- `artifacts-manifest.json`：Release 附件的恢复路径、大小及 SHA256。

当前功能包括4K优先、实际解码尺寸短时显示、正倒序选集、上一集/下一集、倍速、自动连播、断点续播及手动解码方式切换。新增手机画面长按临时2倍速，保持按住向右拖动切到3倍速；电视画面焦点下长按确认键临时2倍速，松开均恢复原速度。实际文字字幕轨默认优先中文，可手动切换或关闭。电视倍速需安卓6及以上；片源标签不代表实测4K。

首页与播放器换源共用同一份28组来源配置：保留原11组，新增15组点播接口和2组直播清单；手机直接进入统一首页。支持标准JSON、MacCMS RSS XML、无code字段的JSON及M3U直播。分类使用每个来源实际声明的ID与层级；茅台、WSY因接口明确禁止检索而标为仅浏览。不同来源的相同数字ID不能互换。接口可用性、剧集更新、4K画质和字幕轨均由上游提供，不能保证片库齐全或每部都有4K／中文字幕。

## 构建边界

这是现有工程的完整源码与必要输入归档，手机工程包含既有 APK 的资源与 smali，尚非完整 Android Studio/Gradle 重写项目。子目录 README 保留历史版本记录，以本页、PRODUCT.md 和最新发布校验记录为当前版本依据。

现有构建脚本仍使用 Windows、Python3.11+、本机 JDK/JBR 与 ASCII 目录别名。恢复附件后，请先阅读两端的构建输入说明与电视 `BUILDING.md`。发布合同刻意不覆盖已有正式包；继续发布需要创建新版本并更新对应合同，不能把归档脚本当作无条件重建命令。

签名私钥和密码不在仓库或 Release 中。要继续给已安装应用覆盖升级，必须在本机恢复原有签名材料；不要创建新密钥后声称签名仍兼容。

## 1.3.9／电视1.3.4 更新

两张截图的96个可读地址及其递归配置已检查。最终增加15组点播和2组直播，原有11组配置及ID保留；同库镜像、旧静态快照和运行脚本订阅分别记录，未作为独立可播片库重复计数。[逐项检查记录](tongpin-4k/ui/unified-sources-1.3.9/SOURCE_AUDIT.md)包含来源归并、失败原因和可验证的边界；新增接口的抽样媒体未证实4K。

## 1.4.0／电视1.3.5 自动选源

播放当前集时后台比较已接入来源：4K优先，同档优先更新正片集号更高、实际覆盖更多的线路；没有合适4K时优先1080p，再回退至其余可用清晰度。无法严格确认同一作品或唯一真实集号时保留原播放，不按列表序号切集、不自动跳到最新集。比较有并发、候选、媒体探测和时间上限，不代表遍历每个来源全部分页或所有影片。

当前视频先播放，最终更合适的结果才自动切换。提交时重新读取当前位置和播放意图，进度拖动、长按倍速期间暂缓；过期结果取消。手动换源或画质选择保留到当前集结束，避免反复抢回。只有明确播放错误才进行一次有界恢复比较，不把几秒卡顿、拖动等待或暂停当作故障定时重启。

实际解码画质仍短时显示。HLS清单宽高、接口尺寸与文字标签是不同证据；自适应最高分辨率不等于当前输出。无水印文字只作为来源标称的弱提示，未知不当作干净版本，应用不检测或涂抹内嵌角标。手机与电视未连接真机，持续播放和遥控表现需要设备验收。


## 1.4.1／电视1.3.6 播放恢复

显式换源和重试为当前集创建新的播放会话，保留有效断点、暂停状态与固定倍速，无需先切到相邻一集再切回。解码器临时返回0或未知时长不再擦掉已记录位置；主动拖到开头仍支持。手机同时隔离旧解码器事件，清理旧全屏视图、暂停位图和音量／亮度／进度提示框；字幕首次绑定跟随实际准备完成状态。电视同步修复同地址重载及seek完成确认。

本轮不改变28组来源配置或4K优先规则，不添加定时重启。已通过主机状态测试、实际DEX／原生ABI、资源和签名核对；未连接真机，截图模糊块是否来自播放器残留尚未复现。若模糊已在上游视频帧中，此次清理播放器覆盖层不会消除它。


## 1.4.2／电视1.3.7 全库片名搜索

首页搜索框默认搜索全部可检索的点播片库，不再受当前浏览来源或分类限制。28组来源中有24个支持点播片名检索；2个仅支持浏览的片库和2个直播源继续保留来源浏览。结果保留真实片库身份，点开沿用现有详情、选集和播放流程。

搜索结果随各片库返回逐步显示，个别来源失败不会清空其他结果。每个来源独立维护分页；继续加载保留已显示结果，失败来源可重试，过期关键词结果不能覆盖新查询。两端复用相同聚合规则，播放器、4K优先、已配置来源与断点逻辑保持。主机验证和最终包校验范围见两端global-search版本目录；未连接真机验收输入法、触摸或遥控操作。

## 1.4.4 手机／1.3.8 电视统一片库

首页汇总点播片库，使用推荐、电影、电视剧、综艺、动漫、纪录片、短剧、少儿等固定分类，不再把各库的原始分类直接堆进首页。分类按来源声明的类别及其层级映射，分类ID始终属于各自来源；未知类别保留在推荐，不靠片名猜类别。直播频道保持独立。同一作品经过保守身份验证后仅显示一个优选条目，优先来源声明画质、明确更新集数，其他来源仍可在换源时查找；不同季、年份、作品类型及身份不明确的条目不强行合并。首页画质标签属于来源信息，不能代替实际解码分辨率；播放阶段继续使用原有4K与同集匹配规则。

全库片名搜索保留自然名称排序，数字1、2、10及“第一季、第二季、第十季”按数值顺序排列，保留原始片名。手机继续使用浅米底、墨蓝文字、蓝色重点和三列海报。异步更新、触摸点击和电视遥控选择保留实际条目身份，防止列表重排后打开其他影片。来源独立分页、失败重试与取消保留，列表逐步加载，不把一次抓取的首屏宣称为所有片库全量。

源码、主机验证和构建证据见两端`ui/unified-library-*/`与当前`verification/`；`ui/search-order-*`保存本轮排序子阶段的历史证据，不能代替最终统一片库审查。28项来源配置、播放器、解码后端、签名和第三方依赖维持原边界。本轮没有手机／电视真机、原生触摸／遥控或持续播放验收。


## 手机1.4.5／电视1.3.9 加载优化

两端异步读取上次成功片库的少量元数据，明确标注“上次片库”，同时刷新真实来源。预览24小时过期，来源配置变化即失效；首次安装或缓存失效仍需联网，不恢复播放URL或网络游标。分类目录与影片页交替调度，按来源轮转取页；进程内复用类别元数据。分组和自然名称排序移到后台，状态回调复用已整理列表。重复海报按URL合并，离开片库暂停未开始任务。

本轮生产范围为两个首页调用者与五份按包镜像的加载辅助类；播放会话、解码器、4K选源策略、真实HTTP接口、28来源注册表和依赖保持原字节。界面继续使用已有浅米与海报布局，未应用待选择的新设计。共享调度140项／端、预览编解码30项／端等主机检查以及APK签名、DEX、SDK与资源验证见两端当前UI和verification目录。未测手机／电视真实加载时间、首次播放或持续播放；上游响应仍影响网络加载。


## 手机1.4.6／电视1.4.0 第一版界面

采用用户确认的浅米片库、墨蓝文字、蓝色重点与中性深色播放器。手机首页仍为三列海报；主播放动作收为上一集、播放／暂停、下一集、选集和设置，时间与进度独立。设置分组显示动作与当前值，原生进度、时间、全屏及点击行为保留。正常／结束／错误和锁屏入口保留，字幕只按实际控制栏高度避让。电视移除过长的横向按钮列表，次级动作进入分组面板，返回焦点与模态交接有明确所有权。低高度／大字使用原生页头滚动与实际行高，保持搜索和竖版封面可读。

加载缓存、后台更新、海报去重、4K择优、换源同集匹配、长按临时倍速、连播及断点规则沿用加载版。各端旧资源ID保留，只各增2个播放器主题；未增加依赖、片源或重写播放核心。设计记录和九轮检查见两端`ui/unslop-*`，方法来自[Unslop by Damir Sokolovsky (@heydamir)](https://github.com/heydamir/unslop)，CC BY4.0。静态图和尺寸矩阵不是真机截图或设备测量；未连接手机或电视做原生视觉、触摸／遥控或持续播放验收。


## 手机1.4.7／电视1.4.1 近期推荐与片名搜索

各影视分类优先推荐近期新作与明确仍在更新的连载，参考来源声明的周／月热度。同一来源、同一周期在本次已取候选内比较相对名次，避免跨站点击量直接比较；缺少热度时按声明更新时间兜底。旧片重新入库不当成新上映。此排序是本地推荐，不是全网权威热播榜，不新增首页网络请求。

全库搜索与播放器换源搜索只保留片名相同或包含完整查询文字的结果，支持全角／大小写／空白归一化，不再接收只有简介或演员命中的其他影片。搜索仍按影片名称自然排序，第一季、第二季、第十季依次排列；可确认的同一作品继续合并并保留全部备选，代表来源沿用4K、更新覆盖与水印文字倾向规则。

保留已确认的浅米三列片库、统一深色播放器、后台加载、上次片库预览、海报去重、播放／进度／字幕／连播和断点行为。旧预览缺少热度字段时按未知处理，后台新结果到达后替换，不为排序清空首屏缓存。28项来源和播放核心没有升级或增加。

主机测试、来源字段核查和独审见各端ui/discovery目录；最终SDK、DEX、ABI、资源ID、签名和成品检查见verification目录。未连接真机做布局、触摸／遥控或持续播放验收。来源的年份、更新时间和点击量可能缺失或不准确。


## 手机1.4.8／电视1.4.2 二级分类与4K分组

保留第一版浅米底、墨蓝文字、蓝色重点和海报片库，在一级分类下加入可横向选择的二级分类，手机与电视采用相同分类表。电视剧细分中国大陆、中国香港、中国台湾、韩剧、日剧、美剧、英剧、泰剧及其他地区；电影按动作、喜剧、爱情、科幻、悬疑、惊悚、恐怖、剧情、战争和动画细分。综艺、动漫、纪录片、短剧和少儿各用对应的常见子类。

新增独立“4K”一级分组，汇总来源明确标注4K、2160p或UHD的影片及专属目录；来源名称含4K不作为影片画质证据，备注明确低清时不因上级4K目录收录。该分组展示来源声明，不伪造实测分辨率，实际画质仍以开播检测为准。

分类读取真实地区、类型字段和完整可信目录层级。例如“电视剧→香港剧→爱情”保留上级香港依据；“海外剧”与内地信息冲突时不猜具体国别。无法确认地区或类型时保留在“全部”，不使用片名、演员或语言推测。可确认的共同出品可出现在对应多个地区。

优先使用来源真实二级目录ID；没有专属子类时沿真实一级目录继续分页后筛选，不只筛当前屏幕。非“全部”或4K页在过滤为空时最多额外跟进两页，仍遵循来源公平队列、原始分页指纹与hasMore，预算用完仍可继续载入。没有新增片源或运行依赖。

缓存按一级和二级隔离，异步回包及触摸／遥控上下文同时核对两级与请求身份；切换一级重置“全部”，搜索仍是独立的全库片名搜索。旧“全部”缓存继续兼容。全库自然名称排序、同作品合并、4K与更新择优、播放核心、拖动进度、字幕、连播、续播和28项来源配置保持。

实际SDK编译、主机逻辑／接线、原方法保护及独审见各端ui/sections目录；最终DEX、ABI、资源ID及签名证据见verification目录。主机检查不等于Android原生布局、触摸／遥控或媒体网络的真机验收。
