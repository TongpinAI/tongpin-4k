# 国内近期热播优先

推荐、各一级分类的“全部”和独立4K分组同步优先展示国内近期热播内容，海外及地区未知的作品保留在后。国内包括明确的中国大陆、香港、台湾、澳门及中国共同出品；仅依据真实地区或完整可信分类目录，不用片名、演员、语言或来源名称猜产地。数据冲突不提升为国内，泛“中国”也不会冒充“中国大陆”细分类。

国内与其余内容各自继续沿用近期、来源周期热度、更新信息的排序。旧首页预览缓存读取后立即重排，无需清缓存或额外请求。热度来自已接入来源元数据及当前候选窗口，不宣称全国权威榜单。

指定韩剧、日剧等二级分类仍按所选地区显示；全库搜索保持片名匹配、自然名称排序与同名作品合并。4K分组收录、4K优先与更新择优、播放器、字幕、选集、拖动、连播、续播及28项来源配置均保持。第一版浅米底、墨蓝文字、蓝色重点与三列海报风格不变，电视同步同一排序策略。

两端各修改3份既有Java，不增运行依赖或资源。每端460项共享逻辑及72项缓存断言通过，并完成实际SDK编译、最终DEX、资源ID和签名检查。未连接手机或电视进行原生界面、遥控和媒体播放实测。
