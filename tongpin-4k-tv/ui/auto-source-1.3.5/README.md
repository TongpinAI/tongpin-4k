# TV 自动选源 1.3.5

播放器在当前视频准备完成后进行一次后台比较；切到新的实际选集后重新比较。当前播放继续进行，仅在同一作品、同一真实选集、候选确实优于当前实际尺寸时提交最终结果。明确的播放失败最多触发一次有界恢复，定位错误不作为片源故障，直播不参与。

共享选择器按目标集的可用清晰度、同档正片最新集与有效覆盖、证据及明确水印标签比较。4K 优先，其次 1080p；清单尺寸与来源标注不冒充实际解码尺寸，来源品牌不作为无水印证据。没有裁切或遮盖画面。

手动选择片源或画质后，本集保持手动选择；该状态及已用比较次数随配置重建保存，下一实际选集恢复自动。后台结果在拖动、原生 seek、遥控长按倍速、对话框或切集期间不会提交，推荐准备后 15 秒失效。提交时重新读取实际进度、固定倍速及播放意图；同 URL 不重建播放器。

未提交队列由有界单线程写入器持有。取消、后台、保存状态、Surface 销毁及 Activity 销毁均取消结果，过期队列删除；成功队列仅在提交后接管。旧 1.3.4 安装包、生产输入快照和历史证据保留。

验证使用当前完整源码、SDK 35、真实队列文件及纯状态测试。尚无电视实机连接，不包含实机播放验收。
