# 同频4K TV 1.3.7 全库搜索

遥控器选择首页搜索框，输入片名即可查全部可搜索点播库。每条结果显示实际来源；可继续加载或重试失败来源，返回详情列表时接着查未完成部分。累计达到2000条时会提示细化片名，来源没有响应会单独计数。4K优先与既有播放器功能保持不变。

非空片名从同一个搜索框查询全部可搜索影视库，当前注册表共 24 组 VOD 参与，2 组仅浏览及 2 组直播不参与。来源按钮和分类保留浏览上下文；清空搜索或“返回浏览”恢复该来源、分类和页码。直播来源仍有独立“搜索频道”入口。

共享 AllCatalogSearch 以 3 个并发请求独立维护每个来源的页码，随到展示部分结果。加载更多追加；失败来源可单独重试；进入详情、播放或后台暂停未完成请求，返回仅继续未完成页。结果保留 provider/id，不按同名跨库合并。列表返回与追加保留原有焦点，网络结果不抢遥控器焦点。

本轮只修改 Home，新增共享搜索 helper，递增版本字段。播放器、播放源注册表、运行时、既有资源及发布的 1.3.6 证据保持原字节。测试覆盖实际纯状态/计数/来源焦点方法与既有播放策略，完整 Java 图经 SDK35 编译；正式 DEX 另做 min21 API/后端守卫与资源 ID 检查。没有连接电视，未声称真机操作或播放验收。
