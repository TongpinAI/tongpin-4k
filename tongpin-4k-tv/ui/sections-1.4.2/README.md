# TV 1.4.2 二级分类

普通片库在一级分类下增加可横向滚动的二级分类行，遥控器可以直接聚焦和选择。例如电视剧可以选择中国大陆、中国香港、中国台湾、韩剧、日剧、美剧、英剧、泰剧及其他地区；选项来自两端共用的分类规则。搜索与直播不显示这行，搜索继续覆盖全部可搜索点播库。

切换一级分类会恢复“全部”。切换二级分类会取消旧请求，清理旧片目、预览、按键状态和滚动锚点；请求、缓存和回调均使用完整的一级＋二级上下文，防止旧地区结果或旧遥控器确认事件进入新分类。返回详情前的分类以及活动重建后的有效选择会保留。

“4K”是独立分组，页面明确标为片源标注；是否实际达到 4K 仍以开播检测为准。它不是新的影片身份类别，也不影响不同作品、不同季的区分。分类不明确的内容保留在“全部”，不通过片名猜地区或类型。

首页海报比例、焦点样式、分组择优和现有播放器保持原实现。本轮 TV 界面只修改 `TvHomeActivity.java`，其他共享分类与预览变更由各自作者封存。没有新增样式、资源 ID、依赖或编译桩。

`tests/run.py` 编译全部 31 个 TV 生产 Java 和已锁定 Media3 接口，复用原有 AAPT 生成的 32 项资源常量；主机检查覆盖分类保存恢复、完整上下文、遥控器真实模型、预览迟到守卫以及既有播放、快进、字幕、换源与 UI 状态。旧固定八分类测试只在本轮临时副本中调整为含 4K 的九分类，历史文件和证据保持原字节。具体最终计数与哈希见测试报告。

这些是代码、SDK 编译与主机状态检查，没有实例化 Android View，也没有连接电视进行实际遥控、布局或持续播放验收。
