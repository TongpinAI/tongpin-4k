# Traditional sections and source-declared 4K

The nine root tabs retain the original work families: recommendation, movie, TV, variety, anime, 4K, documentary, short drama and kids. The 4K tab is navigation based on explicit source resolution/category labels; it does not claim measured resolution or change a work's movie/TV family. Actual playback resolution and source preference stay with the player.

Nested `Section` provides the fixed per-tab secondary choices. Country/region membership uses exact declared `area` aliases or validated category ancestors when area is empty. Conflicting area and directory evidence, generic unknown values, actors, language and titles never establish a specific country. Co-productions can belong to several explicitly declared regions. Generic 港台 is available in the variety grouping and remains ALL in specific-country TV navigation. Genre uses only `vod_class` or declared category ancestors. The nearest specific geographic ancestor wins; every geographic parent is checked for compatibility, and contradictory paths remain unknown before actual-area matching.

The planner requests actual matching child IDs when supplied by the provider, otherwise it preserves full broad-category page cursors and filters metadata after the raw identity fingerprint. A filtered-empty result retains raw `hasMore`. A non-ALL section or 4K request may follow at most two extra empty pages per cursor/round, queued through the same fair three network workers; exhausted local budgets still allow explicit loading of subsequent real pages. ALL browsing makes no extra page requests. Failure retry, cancel/resume, stale work and the 2000-item window keep their original ownership rules.

Tests compile actual models/parsers/schedulers for both packages with the existing org.json host dependency: 156 new cases plus 244 retained catalogue/startup/recommendation assertions per app. They exercise actual-ID planning, raw repeat fingerprints, empty-page budgets, failure/cancel/resume, next-page and result windows. The metadata transport is represented by a controlled Backend; no external network,media,UI rendering or device performance is claimed. Separate unchanged-method evidence records the retained identity,quality,ranking,fetch,queue and lifecycle bodies.
