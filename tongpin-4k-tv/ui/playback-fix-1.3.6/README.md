# TV 1.3.6 播放重载与断点修复

用户可见的变化：可直接重新加载当前集，选择同一地址、同一画质或同一解码方式也会真正重建播放会话；保留有效断点，不再依赖先切到别集再回来。4K优先及同档更新集数优先规则保持不变。

这轮保留原有选源优先级、片库、直播限制、倍速与暂停意图，不使用周期重启。

- 手动换到相同 URL、选择当前画质或当前解码方式，也会实际释放并重建播放核心。准备完成后保留“重新加载”入口，可直接恢复当前集。
- 核心临时返回 0 或未知时钟时，保留本集有效断点及已知时长。显式回到 0 会先更新用户意图，不被旧断点回填。
- 同集换源、重载时只把断点夹到新版本的有效时长内，近片尾不会归零；历史记录原有的近片尾与完成清除策略单独保留。
- Media3 seek 完成须有对应目标的 seek discontinuity、READY/ENDED 与位置确认；普通 READY/events 不再直接完成未确认的 seek。旧实例、已释放核心与旧代际回调被拒绝。

当前完整 24 份 Java 使用实际 SDK 35 和固定 Media3 依赖编译，431 项主机断言通过。原 1.3.5 APK、输入快照和历史证据保留。无设备连接，本轮没有声称复现或验收电视实机卡顿。

手机端同期还清理了旧全屏窗口、暂停截图与亮度／音量／进度浮层。若模糊区域已经存在于片源帧中，本轮不承诺消除该区域。
