# 同频4K TV 1.3.8 统一片库

首页默认聚合26个点播来源，包含2个仅浏览来源；使用推荐、电影、电视剧、综艺、动漫、纪录片、短剧、少儿八个固定入口。分类依据每个来源实际声明的类型和目录，原始ID各自保留，不按数字ID跨库猜测。2个直播来源通过独立“直播”入口浏览、分组和频道检索。主框非空片名仍搜索24个可搜索点播库，并按名称自然排序。

资料足够确认同作品时只显示一个海报，季数、年份和类型冲突不混合；资料不足保留来源独立条目。优先代表由来源标称画质、来源更新说明与明确水印提示择优，不把标称值写成解码实测。原候选及实际provider/API/ID保留在详情“换源”；代表来源详情失败也可直接选择同组其他已知来源。播放器仍提供既有全源换源、实际分辨率短暂显示、4K优先、暂停/进度/倍速和真实选集身份规则。

Group.key独立于代表来源。代表变优或结果插入时按该稳定键及像素偏移恢复焦点/滚动；center/enter按下捕获具体原模型，释放后只能打开同组原候选或取消。详情、后台、窗口失焦、销毁与布局过渡均防止旧点击和隐藏焦点回写。加载更多、失败独立重试及中断继续由每provider/真实目录游标管理；2000候选窗口到限后明确“继续浏览”，保留未消耗页和真实游标。

排序子阶段的全部源码输入、门禁与证据已另存sorting-before，ui/search-order-1.3.8原记录不覆盖。最终发布仍为TV1.3.8/code1308、前版1.3.7；媒体/API/来源表/界面样式不变。主机状态测试、完整SDK编译和DEX检查不代替设备视觉、遥控或实际播放验收，本轮没有连接设备。
