# 同频4K TV 1.3.8 搜索名称排序

全库搜索结果使用共享的名称自然排序副本，处理阿拉伯数字、全角字母数字、S1/S2/S10及“第…季/部/集”中的中文数字；相同名称以实际来源/API/影片ID稳定区分，不合并同名影片，不修改来源标题或原始游标顺序。进度快照复用不可变排序缓存，只有实际新增影片才重新排序。

结果插入前记录真实选中影片和首可见影片的身份与像素偏移，布局时按新索引恢复。卡片点击和selection读取绑定Video，避免用新列表旧position选到另一片。遥控center/enter按下时捕获原Video，暂缓重排；释放后只对该原对象执行原生点击，或因新词/新会话/后台/取消而放弃。方向键沿用原生行为，后台、详情与销毁清理待恢复状态。

本轮只改Home、共享AllCatalogSearch的排序快照，新增CatalogTitleOrder并递增版本。播放器、API、28来源注册表、样式资源、4K选优规则和已发布137全部证据保持原字节。实际主机测试、SDK/D8/API检查不能替代电视遥控/渲染/播放验收，本轮没有连接设备。
