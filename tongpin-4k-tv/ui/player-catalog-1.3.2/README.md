# TV 字幕与遥控临时倍速

在实际视频提供的字幕轨中默认优先中文，允许手动选择已有语言或关闭，并保存该偏好。换集或换源按新视频实际轨重新匹配；没有中文时保留可用轨。只有文字字幕通过原生 TextView 显示，直接使用 Media3 CueGroup 或系统 MediaPlayer TimedText，未新增播放器或 UI 依赖。画面内压入的字幕不能被切换或关闭；不翻译、不生成字幕。

系统核心只把能回调 TimedText 的 type3 轨列为可用。type4 仍显示真实轨信息，但禁用选择；Android 6 及以上可尝试现有兼容核心。兼容核心按实际支持能力和字幕 MIME 禁用已知图片字幕；若收到图片 Cue 也明确提示当前显示层限制。Android 5.0/5.1 保留系统核心，不绕过 API23 边界。

字幕列表只在准备完成、实际轨变化或人的操作时使用；无定时轨查询。默认策略用轨指纹加偏好去重，指纹排除选中状态，避免选择回调循环。选择面板检查当前后端和播放代次；退出、换集、换线路、后台和 seek 清除旧字幕。前台手动暂停可保留当前字幕阅读。字幕与底部控件保持间距。

在视频画面焦点上按住 OK/Enter 500ms 临时 2×，松开恢复当时实际倍速；短按仍打开控制栏。控件按钮保留自己的按键行为。暂停、seek、焦点丢失、换源和销毁取消临时状态，不改固定倍速设置。Android 5.0/5.1 无临时倍速选项。

验证：实际完整 TV Java 图与锁定 Media3 库编译成功，333 条主机策略断言通过；自有 consumer DEX 的 API21/23/26 隔离证明通过。详见 player-catalog-tests.json、consumer-abi-proof.json、source-freeze.json。没有连接电视，未声称完成真实流字幕、遥控按键或渲染验收；最终安装包完整 ABI/签名检查由构建器另行执行。
