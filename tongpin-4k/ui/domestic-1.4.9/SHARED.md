# Domestic-first home ordering

Recommendation, root-category ALL and 4K browsing opt into one domestic-first work tier. Works retain all alternatives; a valid source-declared domestic participant is sufficient, and the existing 4K/update source preference remains intact. Overseas and unknown records are retained after that tier. Both tiers continue to use the previous recent-release/ongoing-series/relative source-period-heat/update ordering.

The signal uses actual area and the existing trusted category ancestry, including conflict guards. Explicit Mainland/Hong Kong/Taiwan/港台 and whole China/CN/PRC or Macao country tokens qualify. These new country tokens do not assign a concrete Mainland secondary section. A whole-China co-production can be consistent with either a matching domestic or foreign declared directory; specific Macao never stands in for Mainland/Hong Kong. Unknown nonempty area is not rescued by directory, title, actor, language or source names. Incompatible paths remain unknown. Missing metadata is not invented.

Old projection overloads default to the old order. Natural title search and explicit secondary sections retain their previous behavior. Browse changes only one projection flag; the complete class otherwise reverses byte-for-byte to148/142. Root-owned preview decoding can call the same package sort after validation for ALL only, keeping schema and old cache content. No network requests, UI changes, source additions or playback changes are introduced.

The host suite compiles actual shared models/policy/scheduler and checks60 new deterministic cases plus400 retained section/startup/recommendation assertions perapp. It covers country aliases, unknown/contradiction guards, genericChina co-productions and concreteMacao negative cases, natural/legacy API stability, same-work4K primary, actualALL/Recommendation/4K browse and a Korean subcategory that keeps old order. Tests use a controlled backend and make no network/device claim.
