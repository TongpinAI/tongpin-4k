# 统一片库共享模型

首页浏览覆盖可浏览的26个点播库，包含不支持片名搜索的两个库；两个直播源保留频道入口。片名搜索仍由原全库搜索器查询24个支持搜索的点播库，界面再应用相同的作品分组，不改搜索请求、分页、取消规则。

固定分类为推荐、电影、电视剧、综艺、动漫、纪录片、短剧、少儿。分类只采用片源声明的类目名称和父子路径；平级明确的“动作片”“韩剧”等可识别，未知或冲突归入推荐。纪录片、短剧、少儿等明确子类优先；动画电影归电影，普通动画不自动归少儿。父目录请求之后仍过滤返回项，防止上游忽略分类或父目录混入其他子类。

重复作品仅在完整片名、唯一年份、明确作品类别一致时归组，保留季/部等原名，缺少关键身份资料的条目各自保留。已知类型冲突不合并。优选顺序为来源标称画质、明确更新集数、末级水印文字提示及稳定来源顺序；没有逐卡详情或媒体探测，标称4K不是实测，不能保证内嵌角标消失。所有候选保留原Video对象，供详情选择备选来源。

浏览最多三个并发请求，使用原CatalogApi及其超时/安全校验；每个来源和类目独立分页，失败不推进页码，取消后的旧回包不写入新一轮。多目录公平排队，不受工作线程队列容量截断。筛选后空页仍遵循原始hasMore，连续重复的非空页停止该游标。

每个结果窗口最多保留2000个来源条目。窗口满时通过continueWindow明确继续浏览；未消耗的页内条目保留偏移，未请求的目录先续跑。去重作用于当前窗口，不宣称一次加载整个远程片库。仅加载成功的数据参与分组，失败来源显示待重试。Source累计成功与失败可重叠，应以本轮请求进度和待重试数向用户说明。

共享主机测试使用两端真实CatalogApi和模型，包含多类目尾部、三并发、同页重试、旧回包、2000窗口、类树合并失败恢复；另有独立真实类树和用户行为用例。没有真机界面或播放验证，也未为这轮下载媒体。
