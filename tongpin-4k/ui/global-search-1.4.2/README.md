# 手机全库搜索1.4.2

使用时直接在首页输入片名，点击“搜索全库”。结果会陆续出现，每条标明实际来源；可点“加载更多”或“重试失败”。想按单个来源与分类找片，可点“返回浏览”。直播节目使用单独的“搜索频道”。

首页原搜索框移到标题下，提示“搜索全部影视片库”，点击“搜索全库”对24个支持关键词的点播库发起搜索。28项注册表保持原样：2个仅浏览来源、2个直播来源明确排除；直播来源单独保留“搜索频道”。空关键词时仍按所选来源和它的真实分类浏览。

`AllCatalogSearch`复用`CatalogApi.fetchPage(provider,query,page,null)`，固定3个工作线程、128个有界队列，初批对全部合格来源各尝试一次；后续加载只请求仍有下一页的来源，不用全局短超时裁掉尾部来源。每源成功后才推进游标，失败保留页码并可单独重试。返回内容以来源ID+API+视频ID去重，保留原Provider对象，不跨库合并同名作品。结果按实际到达顺序累计，已有前缀不重排；过滤后空页仍遵循原始hasMore，非空重复页明确停止并报告。

点开详情、准备播放或进入后台时cancelRound，保留已接受结果与未完成游标，旧轮回包不再提交；返回首页仅resume中断来源。换词或返回浏览永久取消旧handle，销毁关闭工作池。网络取消依赖现有HTTP超时，不宣称阻塞请求立即断开。累计结果/去重存储上限2000条；达到上限仍完成当前批所有来源尝试，但明确提示细化片名，不静默宣称全量。

手机改动只有CatalogActivity和新增AllCatalogSearch，播放器/4K优先规则/28项配置/原生smali均保持1.4.1。自有Java完整34份编译通过，597项主机断言，其中48项执行实际调度器、5项实际caption/身份显示、11项UI接线，其他533项继承播放/队列/手势策略。独立调度器另有27项验证，shared-source-freeze仅绑定该独立证据，不依赖手机caller整图报告。

规范源冻结phone-source-freeze.json，共享双包同体冻结shared-source-freeze.json。实际新DEX与资源/签名/旧证据保护由verification/1.4.2门禁及最终成品检查记录；保留所有旧141证据，不将主机测试当成真机验收。
