# 手机1.4.1：换源、恢复与播放实例修复

用户反馈播放卡住、时间条归零，换源需先切下一集再回来。实际内置GSY没有同URL短路；问题链包括全局manager旧回调在执行时读取新listener、全屏克隆保留旧参数和浮层，以及准备/错误态原生时钟0与有效断点混用。本轮不修改原生GSY或28源表、4K/更新排序。

每次实际prepare使用新的OwnSessionPlayer和EpochManager；全屏只共享本次manager。所有重载入口统一生命周期，原生重试按钮也交回这一入口；旧manager关闭后不能挂回listener，旧事件/准备队列先清，再保留一条真正释放消息。旧全屏同步回窗，清掉旧方向监听、音量/进度/亮度浮层、暂停bitmap和view定时器。

断点只旁路观察既有原生进度读取，返回给原生的数值保持原样，不增加轮询或周期重启。0/未知不擦有效断点，显式seek0先保护目标；近目标读数或真实完成确认后继续，合法关键帧调整在4秒等待后跟随实际正时钟。确认decoder完成立即成为terminal，普通自动候选不能在UI完成事件前抢回已完集。显式同集换源只夹到新片长最后有效位置；历史近尾完成清除规则独立保留。准备态有恢复位置提示，不伪造播放时钟。

真实state2/5提供共同ready点，首次字幕在这里绑定；后台已准备但保持暂停的恢复也补ready，不自动开始播放。既有4K优先、同档更新覆盖、弱水印标签偏好、手动本集pin、上下集、固定/临时倍速、字幕、选集排序均保留。视频内实际水印像素不被裁掉或抹除。

验证包括33份实际Java编译、533条状态/队列/既有播放策略断言、18条实际OwnEpochManager配合host-only原生队列边界测试，以及actual APK smali的字段/方法/继承/反射构造验证。host fake不进入APK。最终签名、DEX、资源证据以verification/1.4.1为准；无手机连接，不声称真机画面或持续播放验收。
