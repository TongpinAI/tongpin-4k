# 手机 1.4.6 播放界面

本轮采用用户确认的第一版方向：浅米片库保持原布局，播放器与设置使用中性深色和蓝色细标记。

原进度条、时间和全屏按钮保留原对象及监听，放入独立的进度行；下方统一为上一集、播放／暂停、下一集、选集、设置五个操作。操作触区至少 48dp，主操作行默认 56dp，随大字体增加高度。原生加载、完成和错误入口保留；仅在活动播放／暂停且底部控件可见时隐藏重复的中心播放按钮。

设置按来源与画质、观看、更多控制、快进快退分组，当前值与动作分开显示。既有动作索引、启用条件、回调及自动连播状态写入保持原逻辑。选集使用较小圆角与蓝色选中边框。播放器和子弹窗使用明确的深色主题与蓝色强调色；首页按钮样式和三列片库未修改。

只修改 `OpenPlayerActivity.java`、`PlayerOptionsSheet.java`、`PhoneUi.java`，新增 `PlayerChrome.java` 及一个包含两个主题的 XML 文件。40 个基线 Java 中其余 37 个保持原字节；播放会话、seek、长按倍速、字幕实现、4K 自动选源、片源表、原生布局和原生代码均保留。本轮仅根据既有字幕覆盖层的明确标记调整可见底栏上方边距，没有修改字幕轨道逻辑。

`tests/run.py` 编译全部 41 个 Java 源，执行 129 项新界面状态／几何／分组断言及 365 项既有 UI、队列、会话、跨源与长按状态断言，并核对 16 项接线／逆变换检查和原生 `getStartButton(): View` ABI。共 494 项断言通过。原 1.4.5 设置分组的视觉预期由本轮新测试替代，旧文件与旧证据不重写。

这些检查覆盖主机状态和编译结果。尚未在手机上验证实际排版、触摸、全屏切换或持续播放；不将示意图或主机测试称作真机结果。最终 DEX、资源 ID、签名和安装包检查由构建环节另行记录。

设计方法适配自 [Unslop](https://github.com/heydamir/unslop)，作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；此处将其方法应用于现有 Android Views 播放器，没有增加运行依赖。
