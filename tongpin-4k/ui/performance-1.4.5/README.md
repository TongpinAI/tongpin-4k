# 手机 1.4.5：片库加载性能

保留 1.4.4 的三列片库、统一分类、全库自然名称排序、来源去重与所有播放器功能，本轮不实施尚待确认的界面重新设计。

- 首页与搜索的分组在独立后台任务中准备，主线程只接收已完成、不可变的结果；同一批纯进度变化不重新排序或刷新卡片。
- 分类按实际来源目录加载，已发现的首批片目可先返回；来源分类元数据在当前片库会话内复用，保留各来源分页、失败重试与取消语义。
- 同一海报 URL 合并在途请求，保持两个工作线程、32 个排队任务和 8 MiB 图片内存缓存。卡片回收取消旧订阅；进入详情、播放或后台暂停未开始的海报任务。保留原图片尺寸、采样和跳转边界。
- 私有首页预览只保存有限片目元数据，不保存播放地址。已有记录在有效期内可先显示，并明确提示正在更新；真实片目到达后替换。新分类、搜索、详情及生命周期变化会拒绝过期回包；仍保留已知来源候选和真实详情读取。

验证分别记录在 `tests/verification.json`、`poster-tests/verification.json`、`cache-tests/verification.json` 和 `../startup-1.4.5/shared-tests/verification.json`。手机 40 份真实 Java 源码已使用 Android SDK 编译为 minSdk 24 的独立 DEX；主包仍检查实际 DEX 方法、字段、继承和高版本 API 守卫。宿主机状态与传输替身测试不代表真机启动或播放测试。

完整运行中使用 `open-sources/staging-1.4.5-r1/own-classes.dex` 作为可恢复的规范构建输入，不依赖临时工作目录。1.4.4 及更早发布证据保持原字节。
