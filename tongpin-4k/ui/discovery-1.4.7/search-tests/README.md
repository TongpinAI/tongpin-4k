# 标题搜索过滤

手机 1.4.7 与 TV 1.4.1 共用同一规则：先统一全角字符、大小写和空白，再检查片名是否连续包含整个搜索词。搜索“纸牌屋”时，仅简介或作者字段提到它的其他作品不会进入结果。匹配不使用排序时的中文序数转换，也不修改来源的原片名。

主搜索仍按原名称自然顺序整理；不同季保留独立作品，原同作品画质与更新择优、备选来源和身份规则保持原逻辑。点播换源列表的非空关键词查询同样过滤并排序；直播、空关键词和仅浏览来源保持原行为。

上游页码、`hasMore` 和原始有效 ID 指纹先保留，再进行标题过滤。过滤后空页可以继续下一页；同一上游页重复时仍停止追加。无关结果不占 2000 条结果上限。

`run.py` 分别编译两端 10 个真实生产类和 JSON 模型，不使用 Android 桩，不发起网络请求。每端 37 项断言覆盖标题相关性、3000 条无关命中、空页续载、重复分页、重试、取消、自然季序、原对象与分组择优；另对六个改动文件做完整逆变换，验证其他逻辑保持基线原文。换源弹窗没有在主机上实例化，实际 SDK 编译和安装包检查由完整构建另行记录。
