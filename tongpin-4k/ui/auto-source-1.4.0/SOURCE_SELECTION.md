# 自动选源的用户偏好

用户明确要求两端一致：优先4K，同档优先更新更全；没有可用4K时优先更新更全的1080p，尽量选没有角标水印的版本。

- 候选必须是同一作品，并包含当前正在看的唯一实际集号。自动选优不能跳到最新一集、按列表位置换集或把预告和彩蛋当作正片更新。
- 画质优先于更新程度。同为4K或同为1080p时，比较实际正片集号与可选覆盖；缺集不能造链接，也不把这些数据说成实测上传时间或更新速度。
- 宽高和来源标签分开处理。播放中的真实画质继续取解码宽高；HLS清单的RESOLUTION是来源声明，自适应上限不等于当前实际输出。相关格式见[HLS RFC8216](https://datatracker.ietf.org/doc/html/rfc8216#section-4.3.4.2)。
- 当前流先播放，后台有界比较，最终只有更合适的结果才切换。提交时保留当前集、实时位置、固定倍速和播放／暂停意图；拖动进度或临时倍速时暂缓，过期结果取消。
- 手动换源、手动画质选择保留到当前集结束，避免自动结果抢回；直播不参与点播自动选源。
- 来源没有可靠的水印检测字段。显式的无水印／带水印文字只作为来源标称的弱提示；未知情况不当作无水印，不按来源品牌推断，也不裁切或涂抹视频画面。

自动比较只涉及已接入来源中能够安全匹配和读取的候选；无法确认作品、集号、清晰度或可用性的候选不作保证。手机和电视没有连接真机，本机测试不能代替持续播放、拖动、遥控和网络验收。
