采集前必读

  • 采集时请开启同步图片，把封面保存到你自己的服务器，避免日后图片地址变更导致封面失效。
  • 分类必须先绑定再采集；SeaCMS 等程序重装或更换资源后要重新绑定，否则数据会进错分类。
  • 采集后播放提示“暂没有数据”、没有选中播放片源、或者播放不了，几乎都是因为还没添加播放器：播放器标识必须填 lzm3u8，各程序的添加方法见对应分页。
  • 采集途中偶尔提示 XML 出错，重新进入采集列表再采一次即可。
  • 已经按老教程填写接口地址、并且采集和播放都正常的，不需要改动。
  • 教程截图来自不同时期的后台版本，截图里的名称、地址只用来示意操作位置，请以本页复制框里的内容为准。

添加采集接口

MacCMS v10 — 定时自动采集（可选）

  1. 后台 → 采集 → 自定义接口，在本站接口的「采集当天」上点右键，复制链接地址
  2. 后台 → 系统 → 定时任务配置 → 添加：状态选启用，名称只用英文或数字（例如 lzm3u8），执行文件选「自定义采集collect」
  3. 附加参数填第 1 步链接中 ? 后面的全部内容（以 ac=cj 开头），执行周期与时间全选，保存
  4. 在任务列表点该任务的「测试」，页面开始输出采集进度即为正常
  5. 在「测试」按钮上点右键，复制链接地址
  6. 服务器面板（宝塔 / aaPanel）→ 计划任务 → 任务类型选「访问URL」，执行周期建议每 30 分钟，URL 地址粘贴第 5 步的链接，添加后点「执行」验证
如果访问该链接提示缺少令牌（token），请到你的后台定时任务页面复制带令牌的完整链接再填入计划任务。

MacCMS v8 — 常见问题

点击采集提示 404？

采集页（admin_maccj.php）跳转时网址参数丢失导致。手动修改浏览器地址，在 admin/ 后面加上 index.php?m=admin-index 即可正常进入采集。

采集后没有更新播放地址或备注？

后台 → 系统 → 采集参数配置，在「二次更新规则」里勾选 播放地址、下载地址、备注，保存后重新采集。

没有选中播放片源？

还没有添加对应播放器。按上方「播放器安装」导入播放器并清空缓存后，再看数据即可正确选中。

SeaCMS — 添加播放来源（必做）

采集后播放提示“暂没有数据”，是因为还没有添加对应的播放来源。

  1. 后台 → 系统 → 播放来源管理
  2. 在「播放来源添加」一栏：来源名称随意，排序填 0，标识填 lzm3u8，点击右侧「保存」
  3. 再下载下方播放器文件放到网站，清空缓存后验证播放

  1. 下载 seacms.zip 并解压，得到 seacms/lzm3u8.html
  2. 把该文件上传到网站的 js/player/ 目录
  3. 确认已添加标识为 lzm3u8 的播放来源 → 清缓存 → 验证播放
下载 seacms.zip（v9.0+）

播放器安装（SeaCMS v8.7 及以下）

  1. 下载 seacms87.zip 并解压，得到 seacms87/lzm3u8.html
  2. 上传到网站的 js/player/ 目录，播放来源添加方法同上
  3. 清缓存后验证播放

飞飞默认使用云播放器解析，可能不支持本站资源。后台 → 系统 → 网站配置 → 视频、文章：视频片头广告时长填 0，清空「节目缓冲广告地址」和「云播放器调用地址」，提交。

飞飞 5.0 — 采集

5.0 的「采集管理 → 一键采集视频」列表里没有自定义资源库的输入框，本站资源用下面这个链接进入：登录飞飞后台，把浏览器地址栏里 ?s= 开头的部分替换成下面这段后回车（fid-99 是分类绑定用的编号，换成任意一个没用过的数字也可以）。

  2. 进入资源库，按右侧分类列表逐个绑定分类后开始采集
若播放异常，请检查播放器的采集标识是否为 lzm3u8。

请求参数

JSON 与 XML 接口参数相同，多个参数用 & 连接。

参数说明示例
aclist 列表（不含播放地址）；detail 或 videolist 详情（含播放地址）ac=detail
t分类 ID，只返回该分类的数据（不含其子分类）t=1
pg页码，从 1 开始pg=2
pagesize每页条数，最大 100；不传时使用本站默认值pagesize=50
h只返回最近 N 小时内更新的数据h=24
wd按名称搜索wd=关键字
ids指定视频 ID，多个用英文逗号分隔，一次最多 200 个ids=1,2,3
year年份或年份区间year=2020-2024
isend1 只要已完结，0 只要连载中isend=1
sort_direction按更新时间排序：desc 从最新开始（默认）；asc 从最早开始，适合全量补采sort_direction=asc
示例
最近24小时 https://cj.lziapi.com/api.php/provide/vod/?ac=detail&h=24
从最早补采 https://cj.lziapi.com/api.php/provide/vod/?ac=detail&sort_direction=asc

MacCMS v10 采集文章

  1. 后台 → 采集 → 自定义资源库 → 添加
  2. 资源名称随意，接口地址填上方文章主接口，附加参数留空

旧客户端配置说明

本节保留旧帮助页的赤兔、多米及播放器缓存教程截图。截图来自当时的客户端版本；界面和参数应以所使用版本为准。

  1. 赤兔、多米等支持自定义资源库的客户端，填写本站 XML 接口；云播放组为 liangzi，M3U8 播放组为 lzm3u8。
  2. 为两个播放组分别添加同名播放器，解析地址使用本页公开的 M3U8 解析接口。下载资源单独使用 providedown 接口和 http 下载器。
  3. 旧静态页提供的 PHP 采集插件已停供。使用客户端内置采集功能；需维护旧插件的站长请自行审核客户端代码后适配。
  4. 老 DPlayer/hls.js 缓存截图仅供对应旧版本核对。请先备份播放器文件，再根据自身 hls.js 版本调整；新版本参数名称可能不同。

MacCMS v8 采集出现 admin_maccj.php 404：旧后台 URL 可能丢失入口参数，可在自身后台 admin/ 后检查 index.php?m=admin-index。请仅在自己的旧版后台操作。
