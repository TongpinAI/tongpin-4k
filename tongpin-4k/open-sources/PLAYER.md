# 同频4K播放器 1.4.4

1.4.4首页整合26个点播来源的传统分类，并对可确认同作品的候选保留一张代表海报；主框24库搜索保持自然名称排序。详情可选全部已知来源，代表来源失败也可切换；原始实际影片和选集仍经现有播放路径读取。打开详情、播放或进入后台会暂停两种聚合请求。播放器源码和行为沿用1.4.3（核心生命周期/断点修复来自1.4.1），没有新增媒体探测或修改4K规则。

当前播放器使用首页同一份28项来源表。换源、重试、解码切换、自动选优和切集统一走新的播放实例；旧manager的迟到事件不能读取新队列，退出旧全屏时同步清理暂停截图、手势浮层与旧定时器。对同集显式重载直接保留当时位置；新片长更短只夹到最后有效位置，不套用历史记录的近尾归零规则。原生时钟返回值不改，瞬间0/未知只保留内存断点；显式跳到0有独立目标保护，合法关键帧调整经有界等待后继续跟随真实时钟。

默认先播原流，再后台一次比较本集真实可用版本，4K优先，同档比较更新覆盖，其次1080p。严格作品与唯一集号验证后，使用提交当时的进度、固定倍速和暂停意图；拖动、临时加速、后台或过期结果不提交。明确点选画质/换源后本集保持手动；新集允许新的一次比较，非定位操作造成的真实加载错误最多再恢复一次。

“换源”先读取实际候选作品、线路和选集；严格作品身份与唯一集号匹配时，经确认保留当时进度及播放意图，无法确认则手选实际集数。不复制原列表序号。PlayQueue v2在私有缓存保存来源/影片/线路元数据，Intent仅传短令牌；旧v1队列仍可读取。

新本地历史与收藏可从首页“我的”进入。后台、切集、销毁或保存状态会取消过期换源请求，旧结果不会覆盖新队列。暂停缓冲状态按真实播放意图保留。字幕、固定倍速、连播、逐集断点、等比全屏、约3秒实测清晰度及手机按住2×/右滑3×保留。

直播按实际频道显示，未知尺寸不标4K；无进度保存、恢复、跨源套用或时间跳转，实际1×播放。电影剧集的固定倍速偏好仍保留。源码及主机测试见 `../ui/unified-sources-1.3.9/`；自动选源主机与源码证据见 `../ui/auto-source-1.4.0/`；生命周期和真实native ABI边界证据见 `../ui/playback-fix-1.4.1/`；统一片库/排序与候选证据见 `../ui/unified-library-1.4.4/`；当前签名APK、实际DEX和资源合同证据见 `../verification/1.4.4/`，没有新增设备验收。

# 公开片源播放器

当前1.3.8仅隐藏原生海报评分角标，播放器及其21份自有Java／157个已编译类沿用1.3.7。上下集、倍速、自动连播、本机断点、3秒画质提示、长按画面临时2×／按住右滑48dp升3×及字幕轨选择继续保留。本轮未改播放器核心、码流或解码策略；首页与摘要修正见 `../ui/native-fix-1.3.7/`，播放功能见 `../ui/player-catalog-1.3.6/SUBTITLES.md` 与 `../ui/player-catalog-1.3.6/player-review.json`。

以下1.1.0集成记录保留历史原文，当前整包结果以 `../verification/1.3.8` 为准。

`OpenPlayerActivity` 是独立原生 `Activity`，只消费片库传来的 HTTP(S) 直链，不调用原软件账号、解析或片源服务。

Intent 契约为 `title/licence/author/source_url` 字符串，`stream_urls/stream_labels` 字符串数组，`stream_widths/stream_heights` 整数数组，以及 `selected` 整数。四个数组必须等长且非空，索引必须有效。链接只允许带合法主机的 HTTP(S)，拒绝嵌入账号密码的 URL。

普通页面使用 16:9 黑色播放区和 GSY 的 contain 模式；画质按钮、重试、来源操作为48dp触区，全屏实例的按钮和底栏也扩到48dp。系统栏与挖孔 inset 作用于普通页面和原生窗口全屏，视频不裁切以填满屏幕。

播放使用现有 `StandardGSYVideoPlayer` 与 `Exo2PlayerManager`。画质标签是来源元数据；“解码分辨率”只读取 `k6.c.D().getVideoWidth()/getVideoHeight()`，在准备完成和500ms后更新，未知尺寸不标成4K。手动画质切换使用 `getCurrentPositionWhenPlaying():long` 与 `setSeekOnStart(long)` 保留进度。

GSY回调接口在此 APK 中混淆为 `m6.h`，共23个方法，未继承其他回调接口。实际 `i` 对应 prepared、`d` 对应播放错误、`f/u` 对应退出/进入全屏。已与原始smali签名和原测试播放器回调逐项核对。

`OrientationUtils` 与 `startWindowFullscreen` 负责横屏和窗口全屏，系统返回通过 `k6.c.C(Context)` 退出；失败会恢复系统栏并提供窗口播放提示。播放失败显示明确恢复操作，用户可重试或选其他画质；没有自动切源逻辑。暂停/恢复遵循进入后台前的播放状态，销毁释放播放器和方向监听，仅播放视图设置keepScreenOn。

来源页面只在用户点击后用合法HTTP(S)外部Intent打开。播放器不抓取网页、执行远程脚本或改变鉴权。
